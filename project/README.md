# Streamlit 기반 중고차 데이터 분석 서비스

중고차 매물 데이터(`data/used_cars.csv`, `data/enriched_used_cars.csv`)를 활용해 브랜드, 연식, 주행거리, 연료 유형, 사고 이력에 따른 가격 분포를 탐색하고 차량 가격을 예측하는 Streamlit 데이터 분석 프로젝트입니다.

## 주요 기능

- 전체 매물 수, 평균 가격, 평균 주행거리, 평균 연식 요약
- 브랜드, 연식, 가격, 주행거리, 연료 유형, 사고 이력 필터링
- 전체/일반 가격대/가격 구간별 분포, 브랜드별 평균 가격, 연식별 평균 가격, 주행거리-가격 관계 시각화
- 가격 상위 1% 초고가 매물을 따로 보여주는 비싼차 모음집
- 학습된 머신러닝 모델을 이용한 중고차 가격 예측
- 차량 정보를 보고 실제 가격을 맞히는 업/다운 가격 예측 게임
- 예산, 차종, 연비, 주행거리, 사고/리콜 위험을 반영한 가성비 차량 추천
- EPA/NHTSA 외부 데이터와 한국 기준가액을 반영한 구입 판독 기능
- 필터링 결과에 대한 간단한 데이터 인사이트 제공
- 조건에 맞는 중고차 목록 테이블 제공

## 실행 방법

1. 가상환경 생성 및 활성화

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

2. 의존성 설치

```powershell
pip install -r requirements.txt
```

3. Streamlit 앱 실행

```powershell
streamlit run app.py
```

## 실행 화면 구성

앱은 상단 탭과 왼쪽 사이드바 필터를 중심으로 구성됩니다.

- `EDA`: 전체 데이터의 매물 수, 평균 가격, 평균 주행거리, 평균 연식을 보여주고 전체 가격 분포, 일반 가격대 세부 분포, 가격 구간별 매물 수를 시각화합니다.
- `시각화`: 필터를 적용해 브랜드별 평균 가격, 연식별 평균 가격, 주행거리-가격 산점도, 사고 이력별 가격 분포를 분석합니다.
- `모델/서비스`: 모델 학습에서 제외한 초고가 매물을 비싼차 모음집으로 따로 보여주고, 사용자가 브랜드, 모델, 연식, 주행거리, 연료 유형, 변속기, 사고 이력 등을 입력하면 학습된 모델이 예상 가격을 출력합니다.
- `가격 예측 게임`: 실제 차량 정보를 보고 가격을 입력하면 UP/DOWN 힌트와 정답 근접 여부를 알려주는 게임형 서비스입니다.
- `외부 데이터`: EPA/NHTSA/CARFAX 보강 데이터 매칭 현황을 확인합니다.
- `차량 추천`: 예산, 차종, 연비, 주행거리, 사고/리콜 위험을 반영해 가성비 차량을 추천합니다.
- `구입 판독 AI`: 차량 조건을 종합해 구매 판단을 돕는 판독 결과를 제공합니다.
- `한국 기준 보정`: 자동차365 또는 보험개발원 기준가액을 CSV로 넣어 한국 시세 기준을 반영합니다.
- `내 차 가격 예측`: 보유 차량 조건을 입력해 예상 가격을 확인합니다.

## 가격 예측 모델

앱 실행 시 `data/used_cars.csv`를 기반으로 가격 예측 모델을 학습합니다.

- 사용 모델: RandomForestRegressor
- 입력 변수: 브랜드, 모델, 연식, 주행거리, 연료 유형, 변속기, 사고 이력, 클린 타이틀 여부
- 예측 대상: 차량 가격
- 초고가 이상치 영향을 줄이기 위해 가격 상위 1% 매물은 모델 학습에서 제외
- 제외된 초고가 매물은 `비싼차 모음집`에서 브랜드, 모델명, 연식, 주행거리, 가격을 별도로 확인 가능
- Streamlit의 `가격 예측` 탭에서 사용자가 조건을 입력하면 예상 가격을 확인할 수 있음

## 발표 핵심 요약

- 데이터 전처리: 가격과 주행거리 문자열에서 기호와 단위를 제거하고 숫자형으로 변환했으며, 결측값은 `Unknown` 처리 또는 분석 대상에서 제외했습니다.
- 주요 분석 결과: 전체 가격 분포와 일반 가격대 세부 분포를 나누어 확인하고, 브랜드, 연식, 주행거리, 사고 이력에 따른 가격 차이를 시각화로 확인할 수 있습니다.
- 예측 서비스: RandomForest 기반 모델을 학습시켜 사용자가 입력한 차량 조건에 대한 예상 가격을 제공합니다.
- 게임 서비스: 실제 매물 데이터를 활용해 사용자가 가격을 추측하고 UP/DOWN 피드백을 받는 인터랙티브 기능을 제공합니다.
- 모델 성능: 보강 데이터와 원화 변환 가격 기준으로 가격 상위 1% 초고가 이상치를 제외한 뒤 평균 절대 오차 약 `14,982,985원`(약 `$9,777`), R² 약 `0.677` 수준입니다.
