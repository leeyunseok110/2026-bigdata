# 중고차 데이터 분석 서비스 발표 요약

## 1. 프로젝트 주제

Streamlit을 활용해 중고차 매물 데이터를 분석하고, 차량 조건에 따른 가격 탐색과 가격 예측 기능을 제공하는 웹 서비스를 제작했다.

- 기본 데이터: Kaggle - Used Car Price Prediction Dataset by Taeef Najib, 4,009행
- 확장 데이터: CARFAX 샘플 매물, EPA 연비, NHTSA 리콜 정보 매칭 후 9,273행
- 주의: CARFAX 샘플은 실시간 시세가 아니라 최신 연식 경향 참고용 보조 데이터

## 2. 데이터 전처리

- `price`: `$10,300`과 같은 문자열에서 `$`, `,`를 제거한 뒤 숫자형으로 변환
- 원본 달러 가격은 `price_usd`로 보존하고, 앱의 표시/예측 기준은 고정 환율 1 USD = 1,532.52원으로 변환
- `milage`: `51,000 mi.`와 같은 문자열에서 단위와 쉼표를 제거한 뒤 숫자형으로 변환
- `model_year`: 연식 분석을 위해 정수형으로 변환
- 결측값: 연료 유형, 사고 이력, 클린 타이틀, 변속기 등은 `Unknown`으로 처리
- 파생 변수: `car_age`, `price_per_mile`, `accident_flag`, `brand_model`
- EPA 연비와 NHTSA 리콜 요약을 매칭해 추천 점수와 구입 판독 근거로 활용

## 3. 주요 시각화 결과

- 전체 가격 분포, 일반 가격대 세부 분포, 가격 구간별 매물 수를 함께 비교하여 대부분의 중고차가 일반 가격대에 몰려 있고 일부 초고가 차량이 존재함을 확인했다.
- 가격 상위 1% 초고가 매물 93건은 비싼차 모음집으로 분리하여 브랜드, 모델명, 연식, 가격을 확인할 수 있도록 구성했다.
- 브랜드별 평균 가격 그래프를 통해 브랜드에 따라 가격 수준 차이가 발생함을 확인했다.
- 연식별 평균 가격 그래프에서 최신 연식일수록 평균 가격이 높아지는 경향을 확인할 수 있다.
- 주행거리와 가격 산점도에서 주행거리가 증가할수록 가격이 낮아지는 경향을 탐색할 수 있다.
- 사고 이력 여부별 가격 분포를 통해 사고 이력이 가격에 미치는 영향을 비교할 수 있다.

## 4. 가격 예측 서비스

가격 예측 기능은 사용자가 차량 조건을 입력하면 학습된 머신러닝 모델이 예상 가격을 계산하는 서비스이다.

- 사용 모델: RandomForestRegressor
- 입력 변수: 브랜드, 모델, 연식, 주행거리, 연료 유형, 변속기, 사고 이력, 클린 타이틀 여부
- 예측 대상: 차량 가격
- 초고가 이상치의 영향을 줄이기 위해 가격 상위 1% 매물은 학습에서 제외

## 5. 모델 성능

- 평균 절대 오차: 약 `14,982,985원` (약 `$9,777`)
- R²: 약 `0.677`
- 해석: 완벽한 가격 산정 모델은 아니지만, 입력 조건에 따른 대략적인 중고차 가격 범위를 참고하는 서비스로 활용 가능하다.

## 6. 서비스 차별점

- 단순 데이터 시각화가 아니라 사용자가 직접 조건을 선택하고 결과를 확인할 수 있다.
- 필터링, 시각화, 실제 데이터 테이블, 가격 예측이 하나의 Streamlit 앱에 통합되어 있다.
- 가격 예측 게임을 통해 사용자가 실제 차량 가격을 추측하면서 데이터 패턴을 체험할 수 있다.
- 분석 결과를 문장형 인사이트로 제공해 데이터 해석을 쉽게 만들었다.
- 가성비 차량 추천, 구입 판독 기능, 한국 기준 보정을 추가해 실제 구매 의사결정에 가까운 흐름으로 확장했다.

## 7. 한계 및 개선 방향

- 차량 옵션, 지역, 판매자 정보가 없어 실제 가격을 완전히 설명하기 어렵다.
- 초고가 차량이나 희소 모델은 예측 오차가 커질 수 있다.
- 향후 더 많은 데이터를 확보하면 예측 정확도를 높일 수 있다.
- 모델별 세부 옵션, 지역, 판매 시점 데이터를 추가하면 더 현실적인 가격 예측이 가능하다.
