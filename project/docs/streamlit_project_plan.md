# Streamlit 기반 중고차 데이터 분석 서비스 계획서

## 1. 프로젝트 개요

### 프로젝트명

중고차 가격 분석 및 탐색 서비스

### 프로젝트 목적

본 프로젝트는 중고차 판매 데이터를 활용하여 차량 브랜드, 연식, 주행거리, 연료 유형, 사고 이력, 변속기 유형 등에 따른 가격 분포와 주요 특징을 분석하고, 사용자가 조건별로 중고차 시장을 탐색할 수 있는 Streamlit 기반 데이터 분석 서비스를 개발하는 것을 목표로 한다.

단순히 데이터를 시각화하는 데 그치지 않고, 사용자가 원하는 조건을 선택하면 해당 조건에 맞는 차량 목록과 가격 통계, 주요 비교 지표를 즉시 확인할 수 있도록 구성한다.

## 2. 프로젝트 배경 및 필요성

중고차 가격은 차량의 브랜드, 모델, 연식, 주행거리, 사고 여부, 연료 유형 등 다양한 요소에 의해 결정된다. 그러나 일반 사용자가 여러 조건을 동시에 비교하며 합리적인 가격대를 판단하기는 쉽지 않다.

따라서 본 서비스는 중고차 데이터를 분석하여 다음과 같은 문제를 해결하고자 한다.

- 브랜드별, 연식별, 주행거리별 가격 차이를 직관적으로 확인
- 사고 이력과 클린 타이틀 여부가 가격에 미치는 영향 분석
- 사용자가 선택한 조건에 맞는 차량의 평균 가격 및 분포 확인
- 중고차 구매 또는 판매 시 참고할 수 있는 데이터 기반 정보 제공

## 3. 사용 데이터

### 데이터 파일

- 경로: `data/used_cars.csv`
- 형식: CSV
- 주요 내용: 중고차 매물 정보와 판매 가격

### 주요 컬럼

| 컬럼명 | 설명 |
|---|---|
| `brand` | 차량 브랜드 |
| `model` | 차량 모델명 |
| `model_year` | 차량 연식 |
| `milage` | 주행거리 |
| `fuel_type` | 연료 유형 |
| `engine` | 엔진 정보 |
| `transmission` | 변속기 정보 |
| `ext_col` | 외장 색상 |
| `int_col` | 내장 색상 |
| `accident` | 사고 또는 손상 이력 |
| `clean_title` | 클린 타이틀 여부 |
| `price` | 차량 가격 |

## 4. 분석 목표

본 프로젝트의 핵심 분석 목표는 다음과 같다.

1. 중고차 가격의 전체 분포를 파악한다.
2. 브랜드별 평균 가격과 매물 수를 비교한다.
3. 연식과 가격의 관계를 분석한다.
4. 주행거리와 가격의 관계를 분석한다.
5. 사고 이력 여부에 따른 가격 차이를 비교한다.
6. 연료 유형 및 변속기 유형별 가격 특성을 분석한다.
7. 사용자 입력 조건에 따라 적절한 중고차 목록과 가격 통계를 제공한다.

## 5. 데이터 전처리 계획

### 결측치 처리

- `fuel_type`, `accident`, `clean_title` 등 결측 가능성이 있는 컬럼 확인
- 분석에 필요한 핵심 컬럼의 결측치는 제거 또는 `Unknown` 값으로 대체
- 가격 분석에 직접 사용되는 `price`, `model_year`, `milage`는 숫자형 변환 후 결측 데이터 처리

### 데이터 타입 변환

- `price`: `$10,300` 형태의 문자열에서 `$`, `,` 제거 후 정수형으로 변환
- `milage`: `51,000 mi.` 형태의 문자열에서 `,`, `mi.` 제거 후 정수형으로 변환
- `model_year`: 정수형으로 변환

### 파생 변수 생성

- `car_age`: 현재 연도 기준 차량 나이
- `price_per_mile`: 주행거리 1마일당 가격
- `accident_flag`: 사고 이력 여부를 이진 값으로 변환
- `brand_model`: 브랜드와 모델을 결합한 표시용 컬럼

## 6. 서비스 주요 기능

### 6.1 메인 대시보드

- 전체 데이터 개요 표시
- 총 매물 수, 평균 가격, 평균 주행거리, 평균 연식 표시
- 가격 분포 히스토그램 제공
- 상위 브랜드별 매물 수 시각화

### 6.2 조건별 차량 검색

사용자가 사이드바 필터를 통해 원하는 조건을 선택할 수 있도록 구성한다.

- 브랜드 선택
- 연식 범위 선택
- 가격 범위 선택
- 주행거리 범위 선택
- 연료 유형 선택
- 사고 이력 여부 선택
- 변속기 유형 선택

필터 적용 후 다음 정보를 제공한다.

- 조건에 맞는 차량 목록
- 필터링된 데이터의 평균 가격
- 최저가 및 최고가
- 평균 주행거리
- 선택 조건에 따른 가격 분포

### 6.3 브랜드별 분석

- 브랜드별 평균 가격 막대그래프
- 브랜드별 매물 수 막대그래프
- 브랜드별 가격 분포 박스플롯
- 특정 브랜드 선택 시 모델별 가격 비교

### 6.4 연식 및 주행거리 분석

- 연식별 평균 가격 변화
- 주행거리와 가격의 산점도
- 연식과 주행거리를 함께 고려한 가격 패턴 분석

### 6.5 사고 이력 분석

- 사고 이력 여부별 평균 가격 비교
- 사고 이력 여부별 매물 수 비교
- 사고 이력이 가격에 미치는 영향 해석

### 6.6 추천 및 인사이트 영역

필터링된 결과를 바탕으로 간단한 인사이트를 문장으로 제공한다.

예시:

- 선택한 조건의 평균 가격은 전체 평균보다 높거나 낮다.
- 사고 이력이 없는 차량의 평균 가격이 사고 이력이 있는 차량보다 높다.
- 특정 브랜드는 같은 연식 대비 가격이 높게 형성되어 있다.

## 12. 한계점 및 개선 방향

### 한계점

- 데이터가 특정 시점의 매물 정보이므로 실제 시장 가격과 차이가 있을 수 있다.
- 차량 옵션, 지역, 판매자 유형 등 가격에 영향을 줄 수 있는 추가 정보가 부족하다.
- 가격 예측 모델을 적용하지 않을 경우 추천 기능은 통계 기반 인사이트에 한정된다.

### 개선 방향

- 머신러닝 회귀 모델을 추가하여 예상 가격 예측 기능 구현
- 브랜드와 모델별 적정 가격 범위 추천
- 사용자 입력값을 기반으로 유사 차량 비교 기능 추가
- 데이터 업데이트 기능 또는 외부 데이터 연동 기능 추가
