중고차 데이터 분석 및 가격 예측 서비스 기획서

1. 프로젝트 개요

프로젝트명

중고차 데이터 분석 및 가격 예측 서비스

한 줄 목표

중고차 매물 데이터를 분석해 가격 분포와 주요 요인을 확인하고, 사용자가 차량 조건을 입력하면 예상 가격을 볼 수 있는 Streamlit 웹 앱을 만든다.

프로젝트 목적

중고차 가격은 브랜드, 모델, 연식, 주행거리, 연료 유형, 사고 이력 등 여러 조건에 따라 달라진다. 이 프로젝트에서는 그런 조건들이 가격과 어떤 관계가 있는지 데이터로 확인하고, 사용자가 직접 조건을 바꿔보면서 가격 패턴을 이해할 수 있게 하는 것을 목표로 한다.

현재 앱은 data/enriched_used_cars.csv가 있으면 이 파일을 우선 사용한다. Kaggle 원본 중고차 데이터 4,009건에 2024~2026년 CARFAX 샘플 매물을 추가하고, EPA 연비 정보와 NHTSA 리콜 요약 정보를 매칭해 추천과 구입 판독 기능에 사용한다.

3. 풀고 싶은 문제

문제정의

중고차 데이터를 이용해 차량 조건에 따른 가격 차이를 확인하고, 사용자가 입력한 차량 정보에 대해 예상 가격을 제공하고 싶다.

분석 질문

  • 중고차 가격은 어떤 범위에 많이 분포하는가?
  • 브랜드별 평균 가격은 어떻게 다른가?
  • 연식과 주행거리는 가격에 어떤 영향을 주는가?
  • 사고 이력 여부에 따라 가격 차이가 생기는가?
  • 사용자가 입력한 차량 조건으로 가격을 어느 정도 예측할 수 있는가?

4. 만들 서비스

프로젝트는 Streamlit 기반 멀티페이지 웹 앱으로 구성한다.

4.1 EDA 페이지

  • 전체 매물 수, 평균 가격, 평균 주행거리, 평균 연식 표시
  • 데이터 미리보기
  • 결측치 확인
  • 주요 수치형 변수 통계 확인
  • 전체 가격 분포, 일반 가격대 세부 분포, 가격 구간별 매물 수 시각화
  • 가격 상위 1% 초고가 매물을 비싼차 모음집으로 별도 표시

4.2 시각화 페이지

  • 브랜드, 연식, 가격, 주행거리, 연료 유형, 사고 이력 필터 제공
  • 가격 분포 히스토그램
  • 사고 이력별 가격 박스플롯
  • 브랜드별 평균 가격 그래프
  • 연식별 평균 가격 그래프
  • 주행거리와 가격의 산점도
  • 필터링 결과에 대한 문장형 인사이트 제공

4.3 모델/서비스 페이지

  • 사용자가 차량 조건을 입력
  • 머신러닝 모델이 예상 가격 출력
  • 유사 조건 차량의 평균 가격 및 중앙값 제공
  • 모델 성능 지표 표시
  • 모델 학습에서 제외한 초고가 매물 목록 제공

4.4 가격 예측 게임 페이지

  • 실제 차량 정보를 보고 사용자가 가격을 추측
  • 입력 가격이 실제 가격보다 낮으면 UP, 높으면 DOWN 표시
  • 10번의 기회 제공
  • 1번째 시도 10점, 이후 시도마다 1점씩 감소
  • 사용자가 데이터의 가격 패턴을 게임처럼 체험 가능

6. 데이터 전처리 계획

  • price: $10,300 형식의 문자열에서 $, , 제거 후 숫자형 변환
  • milage: 51,000 mi. 형식의 문자열에서 쉼표와 단위 제거 후 숫자형 변환
  • model_year: 정수형으로 변환
  • 결측값: 연료 유형, 사고 이력, 클린 타이틀, 변속기 등은 Unknown으로 대체
  • 파생 변수 생성:
  • car_age: 차량 나이
  • price_per_mile: 주행거리 1마일당 가격
  • accident_flag: 사고 이력 여부
  • brand_model: 브랜드와 모델 결합

10. 예상 난관 및 해결 방안

예상 난관 해결 방안
초고가 차량 때문에 평균과 모델 성능이 왜곡될 수 있음 가격 상위 1% 매물을 별도로 분리하고, 모델 학습에서는 제외
범주형 변수가 많아 모델 입력이 복잡함 OneHotEncoder를 사용해 자동 변환
사용자가 예측 결과를 이해하기 어려울 수 있음 유사 조건 차량 평균 가격과 중앙값을 함께 제공
단순 분석 앱처럼 보일 수 있음 가격 예측 서비스와 가격 예측 게임을 추가해 직접 써보는 기능 강화
